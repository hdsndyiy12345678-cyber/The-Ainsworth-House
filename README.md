# The Ainsworth House

엘레나 에인즈워스의 개인용 마법 저택. 대시보드 대신 수채화와 색연필 원화로 구성한 공간 속 사물을 눌러 편지를 읽고, 일기를 쓰고, 작은 생물과 시간을 보냅니다. 외부 서버나 API 키 없이 작동합니다.

## 실행

검증 환경: Node.js 24.22.1, npm 11.9.0, Linux Chromium. Node 22.12 이상을 권장합니다.

```sh
npm ci
npm run dev
```

개발 서버는 기본 포트 5173에서 실행됩니다. `npm run build`는 타입 검사, 프로덕션 번들, 버전별 오프라인 캐시를 생성합니다. `npm run preview`로 프로덕션 결과를 실행합니다. PWA와 서비스 워커는 프로덕션 빌드의 HTTPS 또는 로컬 보안 컨텍스트에서 동작합니다. 개발 서버에는 서비스 워커를 등록하지 않습니다.

## 구현된 경험

- **저택**: 처음 방문 시 실제 문 열림 애니메이션과 건너뛰기, 현관과 9개 방의 고유한 공간 배치, 클릭 가능한 사물, 텍스트 대체 이동, 방문 기록 지도, 브라우저 뒤로 가기, 낮·황혼·밤 조명, 날씨·촛불·벽난로 조작, 선택적으로 켜는 합성 배경음.
- **Owl Post**: 받은 편지·보낸 편지·임시 보관·보관함, 인물 필터와 검색, 읽음 표시, 편지 작성·수정·삭제, 날짜·로컬 전달 상태, 이미지 첨부, 실제 손글씨 폰트 보기, 봉인·종이 애니메이션, 인물 수첩 추가·편집. 기본 인물 7명과 명확히 표시된 창작 예제 편지 1개.
- **다이어리**: 날짜·제목·본문·감정·날씨·사진·스티커·종이·표지, 검색·날짜 필터·책갈피, 자동 저장, 휴지통과 복원, 페이지 전환, 같은 날짜의 편지와 전체 사건 해결 기록 참조.
- **필기**: Pointer Events와 필압을 사용하는 캔버스, 펜·지우개·색·수치 굵기, 실행 취소·다시 실행, 100–200% 확대, 해상도와 독립된 벡터 획 저장. S펜 지우개 이벤트(`buttons & 32` / `button === 5`)를 감지하는 코드와 화면 지우개 대체 조작. 실제 S펜 기기 검증은 미실시.
- **동반 생물**: 고양이·부엉이 외형, 이름, 쓰다듬기·먹이·놀이·휴식, 상태 애니메이션, 친밀도, 시간대 반응, 저장 복원. 하루 첫 먹이만 친밀도를 추가하며 돌보지 않아도 벌점이 없습니다.
- **미스터리**: 완결 가능한 오리지널 사건 The Missing Moonstone. 고정된 진실, 물증 5개, 용의자 3명, 진술 수집, 타임라인·알리바이, 증거 연결 보드, 진행도, 가설·오답·해결 기록, 명시적으로 보관하는 기념 증표.
- **작은 활동**: 서재 기록·수집한 물증 참조, 침실의 편지 추억함, 온실 식물 성장·압화, 초상화 속 열쇠, 다락방 수집품, 별도 필기 연습장, 저장되는 16×16 픽셀 작업판과 PNG 내보내기.
- **통합**: 버전 검증 JSON 백업·가져오기, 덮어쓰기 전 확인, 오프라인 앱 셸·기록 작성, 반응형, 모션 감소, 모달 포커스 제한과 Escape 닫기, 키보드 조작. 작은 화면의 픽셀 작업판은 44px 셀을 유지하며 내부 가로 스크롤을 제공합니다.

## 기록과 백업

데이터는 현재 브라우저·현재 출처(origin)의 **IndexedDB `ainsworth-house` → `snapshots` → `home`**에 저장합니다. 스키마 버전은 `1`이며 `atelier`는 이전 v1 백업 호환을 위한 선택 필드입니다. 일기·편지·인물·이미지(data URL)·필기 획·펫·식물·수집품·수사 진행이 백업에 포함됩니다. 정해진 사건의 진실은 소스의 별도 정적 모델이며 저장·가져오기로 바뀌지 않습니다.

설정과 백업 → **JSON 백업 내보내기**로 다운로드합니다. 가져올 때 파일 구조·버전·중복 ID·벡터 좌표를 검사하고, 명시적으로 확인한 뒤 전체 기록을 교체합니다. 병합과 클라우드 동기화는 없습니다. 백업 가져오기는 30MB 이하, 개별 이미지 첨부는 PNG/JPEG/WebP/GIF 4MB 이하입니다. 많은 이미지를 첨부하면 브라우저 저장 용량 한계에 도달할 수 있습니다. 저장 실패는 하단에 표시됩니다. 브라우저 데이터를 지우기 전에 백업하세요. 서비스 워커 캐시는 기록 저장소와 별개입니다.

추억함은 편지 원본을 참조합니다. 원본 편지 삭제 시 추억함에서도 사라진다는 규칙을 화면에 표시합니다. 서재는 수집한 물증을 참조하며 임의로 수사 내용을 바꾸지 않습니다. 식물·사건·초상화의 소품은 사용자가 보관 버튼을 눌러야 수집됩니다.

## 검증

```sh
npm test
npm run build
npm run test:e2e
```

Vitest는 백업 유효성·손상·중복 ID와 고정 사건의 추론 조건을 검사합니다. Playwright는 현관 애니메이션, 모션 감소, 모든 방 이동, 편지 CRUD·첨부·인물, 일기·벡터 필기·복원, 펫, 사건 전체 진행, 백업 확인·거절, 작은 활동, 키보드·뒤로 가기, 390×844 / 800×1280 / 1280×800 / 1440×900 화면, 프로덕션 오프라인 및 완전한 Chromium 재시작 후 기록 복원을 검사합니다. 화면 캡처는 `test-results/`에 생성됩니다.

Playwright는 `CHROMIUM_PATH` 환경 변수가 있으면 해당 실행 파일을 사용하고, 없으면 `/usr/bin/chromium`, 이후 Playwright 설치 브라우저를 사용합니다. 시스템 Chromium이 없는 로컬 환경에서는 `npx playwright install chromium`을 먼저 실행하세요. 테스트 서버 포트는 5173·4173입니다. 아이콘은 자체 제작 SVG를 `node scripts/icons.mjs`로 PNG로 렌더링했습니다.

## 남은 확장과 검증 범위

실제 Galaxy Tab S9 FE / Android Chrome / S펜 버튼·필압, PWA 설치 UI, Windows 실기기 검증은 아직 하지 않았습니다. Chromium의 화면 크기 에뮬레이션을 실제 하드웨어 검증으로 대신 주장하지 않습니다. 실제 손바닥 거부는 기기/브라우저 지원에 의존합니다.

실제 우편 발송, 공개 서비스 사용자 인증, 기기 간 동기화, 기존 채팅 사건 가져오기, 자유 문서 편집·추가, 자동 계절 변화, 추가 사건은 구현하지 않았습니다. 편지와 교본에는 동봉된 Allura·Nanum Pen 손글씨 폰트를 사용합니다. 실제 인물의 필체를 복제하지 않습니다. 현재 합성 배경음은 짧은 필터 노이즈이며 환경 녹음 자산은 사용하지 않습니다. 초기 버전의 SVG 공간은 아래 Storybook 구현에서 생성 원화로 교체했습니다. 외부 저작권 이미지를 다운로드하여 앱에 포함하지 않았습니다.

다음 단계는 S펜 실기기 입력 검증, 저장 용량 관리와 백업 병합, 추가 오리지널 사건 및 계절별 분위기 확장입니다.

## Storybook 화면 구현과 배포 전 미리보기

승인된 원화에 맞춰 9개 방을 전체 화면으로 바꾸고, 지도·내비게이션·실제 입력창을 별도 레이어로 구현했습니다. 배경·고양이·부엉이·편지·책·불꽃·찻김 등은 생성 원화를 WebP로 인코딩한 `public/art/` 자산을 사용합니다. `src/Scene.tsx`의 기존 실내 SVG 그림은 이 이미지 기반 공간으로 교체했습니다. 서브 화면은 책상·편지지·펼친 책·수사 파일의 구도로 조정했습니다.

- 방과 활동 화면에서 지도를 열 수 있고, 활동을 닫지 않은 채 지도만 보고 돌아올 수 있습니다. 기존 저장 데이터 형식 v1과 IndexedDB 이름은 일반 앱에서 유지합니다.
- 다이어리의 오른쪽 페이지에서도 필기할 수 있으며 별도 손글씨 모드에서 확대/도구를 사용할 수 있습니다. 글자 26개·단어·문장 교본은 각각의 연습 획을 별도로 저장합니다.
- 픽셀 작업판에 채우기·실행 취소/다시 실행·여러 그림 보관·PNG 내보내기를 추가했습니다. 기존 픽셀 그림과 필기는 그대로 불러옵니다.
- 편지 읽기에서 발신인을 수신인으로 하는 답장을 시작할 수 있습니다. OpenAI 답장 요청은 아래 별도 서버 안내를 따릅니다.
- `npm run build:review`로 이미지와 코드가 포함된 `review/ainsworth-preview.html`을 생성합니다. 자세한 열기 방법과 실제 로컬 파일 검증 범위는 [검토 안내](review/README.md)를 확인하세요.

신규 주요 파일: `src/assets.ts`, `src/ManorMap.tsx`, `src/HouseNavigation.ts`, `src/Practice.tsx`, `src/PixelWorkbench.tsx`, `src/storybook.css`, `scripts/build-review.mjs`. 원화 출처 기록은 `docs/art-provenance.json`에 있습니다. `scripts/prepare-art.py`는 원본 생성 이미지가 있는 제작 환경에서 사용하는 선택적 인코딩 도구이며 일반 설치/빌드 경로에는 포함되지 않습니다.

검토용 HTML은 서비스 워커 등록과 외부 이미지 요청을 사용하지 않으며, 운영용 IndexedDB와 별도의 미리보기 저장소를 사용합니다. Galaxy Tab S9 FE 실기기·S펜 버튼 동작, 실제 Netlify 배포와 유료 OpenAI 호출은 검증하거나 실행하지 않았습니다.

## OpenAI 편지 보강

실제 손글씨 폰트(영문 Allura, 한글 Nanum Pen)를 자체 호스팅하고 독립 HTML에도 포함합니다. 라이선스는 `public/fonts/*-OFL.txt`에 있습니다. 지도 버튼은 데스크톱 150px·휴대폰 112px로 줄였으며, 반짝이에는 배경에 묻히지 않는 원형 받침을 추가했습니다.

AI 편지는 선택한 인물·편지 본문을 확인한 경우에만 OpenAI로 전송합니다. 서버 큐, UTC 하루 호출 한도, 동일 전송 ID 중복 방지, 수신·실패·재확인 상태, 새 편지 표시를 구현했습니다. **서버 키는 아직 없어 실제 OpenAI 호출은 검증하지 않았습니다.** 일반 앱은 키 없이 기존 로컬 기능을 계속 사용할 수 있습니다.

[AI 우편 실행 및 보안 설정](docs/AI-POST.md)을 참고하세요. `npm run dev:ai`가 별도 Node 서버를 시작합니다. 검증은 `npm test`, `npm run test:ai`, `npm run build:review`, `npm run test:e2e`입니다. Netlify 배포는 수행하지 않았으며 정적 업로드만으로 AI 서버가 실행되지는 않습니다.
