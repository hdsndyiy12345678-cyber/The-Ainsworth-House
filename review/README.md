# 배포 전 HTML 미리보기

`ainsworth-preview.html`은 앱 코드·CSS·원화 22개가 포함된 단일 HTML 파일입니다. 약 12.6MB이며, Netlify에 올리지 않고 디자인과 주요 동작을 검토하는 용도입니다.

1. GitHub에서 이 파일을 열고 **Download raw file**을 눌러 저장합니다. 파일이 크기 때문에 코드 미리보기가 표시되지 않아도 다운로드는 할 수 있습니다.
2. 저장한 HTML을 **PC의 Chrome 또는 Edge**에서 엽니다. 이미지 폴더나 별도 설치는 필요하지 않습니다.
3. 입장 후 방의 사물, 좌측 아래 지도, 우측 위 설정을 눌러 보세요. 편지·일기·수사·작업실 화면에서도 지도를 열 수 있습니다.
4. 설정에서 낮/밤과 애니메이션을 바꿔 비교할 수 있습니다. 작은 화면의 방은 좌우로 둘러볼 수 있습니다.

미리보기는 일반 앱과 다른 IndexedDB(`ainsworth-house-preview-v1`)를 사용합니다. 실제 사이트의 기록을 자동으로 읽거나 수정하지 않습니다. 미리보기에서 만든 기록은 해당 브라우저에 저장되지만 파일을 여는 방식/브라우저의 로컬 파일 정책에 따라 저장 지원이 다를 수 있으므로 중요한 기록은 JSON으로 백업하세요.

이 환경의 관리형 Chromium은 `file://` 탐색을 정책으로 막고 있어 파일 URL 자체의 열기는 검증하지 못했습니다. 대신 동일한 HTML 바이트를 독립 문서로 제공하고 인터넷/하위 리소스 요청을 차단한 상태에서 화면 실행·방 이동·일기 저장·새로고침 복원을 검증했습니다. 시스템의 HTML 미리보기 앱은 JavaScript를 실행하지 않을 수 있으니 일반 PC 브라우저를 사용하세요.

AI 답장은 별도 OpenAI 서버와 편지별 전송 확인이 필요합니다. 이 HTML에 API 키나 서버는 포함하지 않습니다. 실제 우편 발송·클라우드 동기화는 제공하지 않습니다. [AI 연결 안내](../docs/AI-POST.md)를 참고하세요. 이 파일을 Netlify 업로드용 `dist`에 복사할 필요는 없습니다. 실제 배포는 검토 후 별도 단계입니다.

다시 만들기:

```sh
npm ci
npm run build:review
```

일반 `npm run build`는 기존처럼 Netlify용 `dist`를 만들고, `build:review`는 추가로 이 HTML을 만듭니다. 원화는 `public/art/`에 포함되어 있으므로 정상 빌드에 이미지 생성이나 Python은 필요하지 않습니다.

Allura(영문 필기체)와 Nanum Pen(한글 손글씨) 폰트도 HTML에 포함되어 외부 폰트 서비스에 접속하지 않습니다. 실제 OpenAI 호출은 서버 키 설정 후 확인해야 합니다.
